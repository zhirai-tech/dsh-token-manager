# Security policy

## Reporting a vulnerability

Please email **xtang3125@gmail.com** with:

- affected version
- a short description and impact
- reproduction steps (no secrets, no full session logs)
- the output of `/token-manager/api/health` if relevant

We aim to acknowledge within 7 days. Do not open a public issue for an unpatched vulnerability.

## Scope notes

- The plugin stores all data locally under `%DSH_HOME%\dsh-token-manager\` and makes no network requests.
