# Contributing

DSH Token Manager is proprietary software (UNLICENSED). External code contributions are not accepted, but the following are welcome:

- bug reports with reproduction steps
- compatibility reports (DSH version / OS / model provider)
- feature requests for token accounting and cost analysis
- security reports (please read `SECURITY.md` first)

Please do not open pull requests that copy or modify the compiled bundles; the build is produced from the private source tree.
