## 0. 先说一个硬阻塞：子代理会话拿不到 live Client Inspect

```
cordis_inspect_query(platform=client, provider=Slots, method=listSubTree)
→ Error: Slots.listSubTree: Client inspect query Slots.listSubTree timed out after 10000ms.
```

不是「页面没打开」。我把 62186 的 Web GUI 真正打开（cookie 鉴权通过，页面完整渲染、82 个 client 入口全部挂载），并在页面 console 抓到根因：

```
[cordis-client-runner] inspect query Slots.listSubTree failed:
Error: session/agent-busy: session "83b878e5-8b83-428e-ac8a-ac9ef5f21282" is owned by subagent routing
    at Object.resolve (…/dsh-cordis-client-runner/client.js…)
    at async ClientCordisInspectRegistry.query (…)
```

机制（源码确认 `@deepseek-ai/dsh-cordis-client-runner/lib/client.js:7473-7479,7566-7570`）：页面收到 `cordis/inspect-query` 事件后，必须回调 `ctx.remote.dynamicCordisRunner.resolveInspectQuery(agentId, …)` 把结果写回 Host；**子代理拥有的 session 在这条回写路径上被判为 `session/agent-busy`**，所以 Client Inspect 永远不会 resolve，只能超时。

同理 `client/Theme.listTokens`、`client/Service.listService`、`client/Builtin.listBuiltins` 全部不可用。

> 影响：本文 §1 §3 的 slot / 主题 token 清单改用「随包发布的 client 源码 + README + 已安装插件源码」确认，可信度等价或更高（能直接引用注册语句），但不是 live 拓扑快照。

## 1. Slot 清单与承载能力结论

### 1.1 Slot 系统是什么（源码事实）

- Slot 注册表是 `ctx.slots`，实现于 `@deepseek-ai/dsh-client-ui-renderer/lib/client.js:1305` 的 `SlotRegistry`（`SlotCore` 来自 `@deepseek-ai/dsh-client-ui-slots`，注册语义/声明台账在 core 侧）。渲染入口是 `uiRenderer.mount()` 后唯一的 `renderSlot('root')`（README 原文："The renderer performs the sole context-level `renderSlot('root')` call"）。
- 注册方法只有两个：`ctx.slots.register(options, Component)` 与 `ctx.slots.registerFactory(options, Component)`；两者都包在 `ctx.effect(...)` 里，**返回 disposer，插件卸载/热更自动回收**（`client.js:1813-1820`）。
- `ctx.slots.inject(slotKey, callback)` 是「声明感知」等待器：目标 slot 尚未声明时排队，声明提交后回调才执行；compact/unload 反向回收（`client.js:1368-1420`）。**第三方插件必须用它**，否则在替换/精简过的 composition 里会静默失效。
- 作用域（scope）：`root`、`session`、`session-maybe`。root 作用域 = 全局（所有会话共享一个实例）；session 作用域按会话实例化。

### 1.2 能承载「整页 / 标签页 / 侧栏面板 / 设置页 / 仪表盘卡片」的确切 slot

> 「能力」列：**整页** = 可占满中栏渲染独立页面；**面板** = 侧栏/右栏 dock 区域；**卡片** = 小装饰/状态条；**入口** = 只提供导航 icon。

### 1.4 关键工程注意事项（源码可证）

1. **入口页顶部 48px**：`ui-layout` 在 root 上发布 `--dsh-frame-top-clearance`（48px，Windows 为标题栏高度）；README 明确「entry pages in the main panel (plugin manager and similar, not the conversation) pad their top by it」。自建 `main` 页必须 `padding-top: var(--dsh-frame-top-clearance, 48px)`，否则标题被窗口 chrome 压住。
2. **`main` 是 root 作用域**：一个实例、所有会话共享 → 适合「全局统计仪表盘」；若要「只看当前会话」，需在页面内用 `useSessions`/`useSession` 自己取当前会话。
3. **`main` 的 key 必须已注册**：`ctx.layout.selectPanel(id)` 对一个未注册的 key 会 **throw 且不改变当前选中**（`ui-layout/README.md`），所以「先注册 panel，再允许导航」。
4. **无占位者时不渲染**：`sidebar.panellist` 没有注册时列表与间距都不渲染；`shell.bottom` 空内容不占位。
5. **注册顺序无关**：用 `ctx.slots.inject(slotKey, () => ctx.slots.register(...))`，可兼容声明晚于消费者。
6. **UI 里禁止出现未本地化硬编码文案**（官方有 `verify-client-ui-i18n` 校验；对我们的插件是约定，见 §3.2）。

## 2. 注册示例（照真实包模板写）

### 2.1 整页 + 左栏入口（官方 `ui-plugin-manager` 同款最小形态）

```js
// client 入口（lib/client.js 的 factory 内）
const PANEL_ID = 'token-manager';
const NS = 'tokenManager';

export const inject = ['slots', 'locale', 'layout', 'remote'];

export function apply(ctx) {
  // 1) 字典
  ctx.effect(() => ctx.locale.register(NS, { zh, en }), 'token-manager: dictionaries');
  const t = ctx.locale.bind(NS);

  // 2) 左栏入口（icon 组件，list slot）
  ctx.slots.inject('sidebar.panellist', () => ctx.slots.register({
    name: 'sidebar.panellist',
    id: PANEL_ID,
    order: 20,                 // 数字越小越靠前；官方 plugins=0
    label: () => t('panel'),
    locale: NS,                // 让组件拿到注入的 t
  }, PanelIcon));

  // 3) 整页（keyed slot，key 与上面 id 相同）
  ctx.slots.inject('main', function* () {
    yield ctx.slots.register({
      name: 'main',
      key: PANEL_ID,
      locale: NS,
      inject: () => ({ api: apiFace }),   // 组件通过 props.api 拿到宿主能力
      children: {
        // 只有一个组件的页面可以完全省略 children
      },
    }, DashboardPage);
  });
}
```

### 2.2 第三方真实先例：`dsh-mnemon` 的「技能管理」独立面板（可直接对标的写法）

```js
  const stopMain = ctx.slots.register({
    name: 'main',
    key: SKILLS_PANEL_ID,                    // e.g. 自定义 id

    seat.set(false);                          // 降级：退回自有入口
    stopIcon?.();
    stopMain();
    throw error;
  }
  return () => { seat.set(false); stopIcon?.(); stopMain(); };

```

它的导航就是：

```js
const navigation = {
  open:  () => ctx.layout.selectPanel(SKILLS_PANEL_ID),
  close: () => ctx.layout.selectPanel(null),
```

**可复用模式（强烈建议照抄）：**
- 用两级 `slots.inject` 包住「入口 + 整页」这一对注册（同生共死）；
- 用一个 `seat` 布尔记录原生态座位是否可用，不可用时**降级到自有入口**而不是整块 UI 消失；
- `label` 写成 `() => t(key)` 函数形式，语言切换时无需重新注册；
- 所有注册在 disposer 里逆序清理。

## 3. 主题与本地化

### 3.1 主题 token

**权威来源**：`@deepseek-ai/dsh-client-ui-theme` 的 `BUILTIN_INSPECT_TOKENS`（`lib/client.js:1531+`，即 `Theme.listTokens` 的数据源）+ 其 `design-platform.css` 内联样式表。**token 前缀是 `--dsw-*`（不是 `--dsh-*`；`--dsh-*` 是布局/字体/滚动条那批）**。

已确认的 token 族（`requiresLightAndDark: true` 表示必须同时提供明暗两套）：

- 底/层：`--dsw-alias-bg-base`、`--dsw-alias-bg-layer-1`、`-bg-layer-2`、`-bg-layer-3`、`--dsw-alias-bg-overlay`

### 3.2 本地化（zh/en）

- 服务：`ctx.locale`，实现 `@deepseek-ai/dsh-client-locale`。
- 注册：`ctx.locale.register(ns, { zh, en })`——**两种随包语言必须同时给全**（编译期类型会校验每个 key）。
- 取值：`ctx.locale.bind(ns)` → `t`；slot 注册时写 `locale: ns` 会让框架把 `t` 作为 prop 注入组件（`ui-renderer` `standardKit`，`client.js:742-746`）。
- 插件文案（`LocalizedText`，如插件标题/描述）：`ctx.locale.resolveText(text)`；字面量原样返回。
- 新增语言包：`ctx.locale.addLanguage({ id, label, fallback })` + `ctx.locale.register(ns, lang, {...})`（外部 id 的 fallback 链必须终止于 `en`）。
- **JSON 放哪**：随包语言文件在包内 `locale/zh.json`、`locale/en.json`（`package.json` 里以 `"./locale/*.json": "./locale/*.json"` 导出）。真实样例：`dsh-mnemon/locale/zh.json`（219 B）、`dsh-mnemon/locale/en.json`（17 B）。构建时把 JSON `import` 进 client 入口，再 `ctx.locale.register(NS, { zh, en })`。
- 行为：切换语言时 slot 内文案**实时更新**（字典 revision 驱动），不需要重新注册。
- 约定：UI 里所有中文/英文文案都走字典，禁止内联硬编码（官方 `verify-client-ui-i18n` 就是查这个）。

最小示例：


## 4. Host → Client 数据通道对比与推荐

### 4.1 三条通道的真实形状

#### ① `ctx.webServer.register` 自定义 HTTP 路由（**推荐**）

- 形状（源码 `@deepseek-ai/dsh-host-webserver/lib/index.js:326-333, 378-394`）：

```ts
type WebRoute = {
  kind: 'exact' | 'prefix'
  path: string                       // '/token-manager/api'
  handler(req: IncomingMessage, res: ServerResponse): void | Promise<void>
}
ctx.webServer.register(route): () => void          // 返回 disposer；重复 (kind,path) 抛错
ctx.webServer.registerUpgrade({ path, handler(req, socket, head) }): () => void  // WebSocket/SSE
ctx.webServer.getOrigin(): string                  // 'http://127.0.0.1:62186'
```

- 匹配规则：先整表 exact → 再最长 prefix → 最后 fallback（SPA dist）。
- **鉴权不在 webserver 里**：路由命中即直接调 handler，**不会**自动过 browser-auth 围栏。第三方插件必须自己加围栏。已安装插件 `dsh-better-sidebar` 的写法（`lib/index.js:8976-8990` 与 `const fence = (req) => ctx.connection.requestRejection(req) === void 0;`）：

```js
ctx.effect(() => ctx.webServer.register({
  kind: 'prefix',
  path: '/token-manager/api',
  handler: async (req, res) => {
    if (ctx.connection.requestRejection(req) !== undefined) { res.writeHead(403); res.end(); return }
    if (req.method !== 'POST') { res.writeHead(405); res.end(); return }
    …
  },
}), 'token-manager: /token-manager/api')
```

- 浏览器侧：同源 `fetch('/token-manager/api/...')`，**cookie 自动携带**（`dsh-client-connection` 的会话 cookie 是 `HttpOnly; SameSite=Strict`，见 `browser-auth` 的 `sessionCookie`），无需前端处理 token。
- 优点：完全掌握分页/排序/CSV/流式；不依赖官方 typert 代码生成；已安装插件（better-sidebar 7 条 HTTP + 3 条 upgrade 路由）走的就是这条路。
- 缺点：类型要自己维护；必须自己做鉴权、输入校验、CSV 注入防护。

#### ② `@Remote` + typert（类型化 RPC）

- 形态：Host 服务方法加 `@Remote('name')` / `@Remote({ mode: 'stream' })`，Client 用 `ctx.remote.<namespace>.<method>()`；事件用 `ctx.remote.$on('event', …)`。
- 由 `@deepseek-ai/dsh-typert-*` + API Gateway 承载；Client 侧命名空间由官方 `@deepseek-ai/dsh-api-remotes` 装配（`ctx.remote.$mount()`），Host 侧需要 typert schema 贡献（`typert.register(...)`，产物 `lib/typert.host.js` 是**生成文件**）。
- 事件白名单是**闭合的**：`API_REMOTE_FORWARDED_EVENTS` 在官方包内硬编码，第三方插件不能新增（`dsh-api-remotes/README.md`「Forwarded Host events」）。
- 优点：类型安全、取消/流式/重连由框架处理。
- 缺点：对独立第三方插件成本高（要接 typert 生成链路 / 手写 schema 贡献）；事件推送不可扩展；**二进制/CSV 下载不自然**。

#### ③ `sessionProjections`

- 是 **Host 侧**的增量会话状态折叠服务：插件 `ctx.sessionProjections.register(def)`，读 `stateOf(session, key)`（`dsh-agent-loop/lib/index.js:1581-1583`、`dsh-agent-instructions:1385`）。
- 它**不是**一条客户端传输通道：要把结果送到浏览器，仍需 ① 或 ②。
- 适用：把「本会话累计 token / 每轮用量」做成可复用投影，供 UI 或工具读；不适用于「任意条件分页查询历史库」。

### 4.2 推荐方案（DSH Token Manager）

| 需求 | 推荐 | 理由 |
|---|---|---|
| 仪表盘分页查询（按时间/模型/会话筛选） | **① `kind:'prefix'` HTTP 路由 + POST JSON**（`/token-manager/api/report`） | 分页参数/排序/聚合键完全自控；同源 cookie 免 token；已有成熟先例 |
| 导出 CSV / 大结果下载 | **① HTTP 路由 + `Content-Disposition` 流式响应**（GET `/token-manager/api/export.csv`） | `@Remote` 不适合二进制/流式附件；HTTP 可直接 `res.write` 分块 |
| 导出进度 / 实时刷新 | ① 的 `registerUpgrade` 起 SSE（或用轮询） | 官方事件白名单闭合，第三方只能自带流 |
| 会话实时小徽标（左栏行内） | 轮询 HTTP（10–30s）或 SSE | 同上；数据量小 |
| 长期存储 / 聚合计算 | Host 侧自有存储（`ctx.storage` / 文件 / sqlite），只暴露查询接口 | 遵守 §8 安全规则：聚合与原始数据留在服务端 |

**最小骨架（Host 半）**

```js
// index.js  (Host 入口，Cordis 插件)
export const name = 'dsh-token-manager';
export const inject = ['webServer', 'connection'];

export function apply(ctx) {
  const json = (res, code, data) => {
    res.writeHead(code, { 'content-type': 'application/json; charset=utf-8', 'cache-control': 'no-store' });
    res.end(JSON.stringify(data));
  };

  ctx.effect(() => ctx.webServer.register({
    kind: 'prefix',
    path: '/token-manager/api',
    handler: async (req, res) => {
      // 1) 来源/宿主/操作者围栏（必须，路由本身不做鉴权）
      if (ctx.connection.requestRejection(req) !== undefined) return json(res, 403, { error: 'forbidden' });
      const url = new URL(req.url ?? '/', 'http://dsh.invalid');
      const method = url.pathname.slice('/token-manager/api/'.length);

      try {
        if (method === 'report' && req.method === 'POST') {
          const body = await readJson(req, { maxBytes: 64 * 1024 });     // 自己校验 schema
          const page = Math.max(1, Number(body?.page ?? 1));
          const size = Math.min(200, Math.max(1, Number(body?.size ?? 50)));
          return json(res, 200, await queryReport({ ...body, page, size })); // 服务端分页
        }
        if (method === 'export.csv' && req.method === 'GET') {
          res.writeHead(200, {
            'content-type': 'text/csv; charset=utf-8',
            'content-disposition': 'attachment; filename="token-usage.csv"',
            'cache-control': 'no-store',
          });
          res.write('\uFEFF');                                    // Excel UTF-8 BOM
          res.write('date,model,session,input,output\r\n');
          for await (const row of streamReport(url.searchParams)) res.write(csvRow(row));
          return res.end();
        }
        return json(res, 404, { error: 'unknown method' });
      } catch (error) {
        return json(res, 400, { error: 'bad-request' });           // 不泄漏堆栈/路径
      }
    },
  }), 'token-manager: http api');
}
```

**最小骨架（Client 半，页面里取数）**

```js
async function fetchReport(params, signal) {
  const res = await fetch('/token-manager/api/report', {
    method: 'POST',
    headers: { 'content-type': 'application/json' },
    body: JSON.stringify(params),
    credentials: 'same-origin',
    signal,
  });
  if (!res.ok) throw new Error(`report failed: ${res.status}`);
  return res.json();
}
```

**安全要点（对齐全局 §8 规则）**：服务端重新校验所有分页/过滤参数；CSV 单元格做前缀转义（`= + - @ \t \r` 前加 `'`）防公式注入；错误不返回堆栈；导出加行数上限与超时；不要把密钥/原始会话全文放进响应。

### 5.1 硬事实（本机实测）

| 事实 | 结果 |
|---|---|
| 本机 Node | `v24.14.0` |
| DSH 是否自带 esbuild / tsdown / typescript | **否**。`app.asar` 内仅有两个 `tsdown.config.ts` 源文件，无任何构建器/编译器二进制 |

### 5.2 client 入口的**确切**格式（从已安装包头部抄的原文）

`…\node_modules\dsh-mnemon\lib\client.js:1-10`：

```js
window.__ModuleLoader__.load({
	id: "dsh-mnemon",
	factory: (require) => {
		var module = { exports: {} };
		var exports = module.exports;
		Object.defineProperty(exports, Symbol.toStringTag, { value: "Module" });
		let react = require("react");
		let _deepseek_ai_dsh_client_ui_primitives = require("@deepseek-ai/dsh-client-ui-primitives");
		let react_dom = require("react-dom");
		let react_jsx_runtime = require("react/jsx-runtime");
		// …bundle 主体（CJS）…
		return module.exports;   // ← 末尾
	}

```

配套事实（`dsh-client-modules` README）：
- 执行 bundle **只注册 factory**；模块体副作用（含 CSS 注入）在 `factory(require)` 被**首次 materialize** 时才跑，结果缓存在 `loadCache`。
- `require` 解析顺序：平台静态表（`PLATFORM_MODULES`：react / react-dom / 共享 client 包）→ 已 materialize 记录 → boot graph 行 → 已注册 factory；其它一律 throw。
- 一个 bundle = 一个模块节点；`import()` 会被拆成 `require.async('./client.<name>.js')` 分块（可选，不必用）。
- 支持 source map：`client.js.map` 由 `/plugins` 单独按需返回；上线后 HMR 依据 mtime/ctime/size 换 revision。
- **bundle 必须在启动前构建好**：缺失时激活会带明确构建提示失败。

**CSS 注入与卸载清理**（官方语义是「插件-owned 样式随卸载/HMR 移除」；自己插自己清，最稳）：


### 5.4 无网络时的降级方案（完全可行）

不装任何构建器，手写 `lib/client.js`，用 `React.createElement` 代替 JSX，格式与 §5.2 完全一致：

```js
window.__ModuleLoader__.load({
  id: 'dsh-token-manager',
  factory: (require) => {
    var module = { exports: {} }; var exports = module.exports;
    var React = require('react');
    var h = React.createElement;

    function DashboardPage(props) {
      const [rows, setRows] = React.useState([]);
      React.useEffect(() => {
        const ac = new AbortController();
        fetch('/token-manager/api/report', { method: 'POST', headers: { 'content-type': 'application/json' },
          body: JSON.stringify({ page: 1, size: 50 }), credentials: 'same-origin', signal: ac.signal })
          .then((r) => r.json()).then(setRows).catch(() => {});
        return () => ac.abort();
      }, []);
      return h('div', { className: 'tm-page' },
        h('h1', null, props.t('title')),
        h('table', null, rows.map((row) => h('tr', { key: row.id }, h('td', null, row.date), h('td', null, row.model)))));
    }

    function PanelIcon() { return h('span', { 'aria-hidden': 'true' }, '◔'); }

    function apply(ctx) {
      ctx.effect(() => ctx.locale.register('tokenManager', { zh, en }), 'tm: dict');
      ctx.slots.inject('sidebar.panellist', () => ctx.slots.register(
        { name: 'sidebar.panellist', id: 'token-manager', order: 20, label: () => ctx.locale.bind('tokenManager')('panel'), locale: 'tokenManager' },
        PanelIcon));
      ctx.slots.inject('main', () => ctx.slots.register(
        { name: 'main', key: 'token-manager', locale: 'tokenManager' }, DashboardPage));
    }
    exports.apply = apply;
    exports.inject = ['slots', 'locale'];
    return module.exports;
  }
});
```

降级方案的代价：无 TSX 类型检查、无 CSS modules、维护性差；**仅在 npm 不可用/无法执行二进制时使用**。两者的 Cordis 契约 100% 相同，切换无风险。

## 6. 风险与未验证项

### 6.1 已确认的硬限制

| # | 限制 | 影响 | 处置 |
|---|---|---|---|
| 1 | **子代理会话拿不到 live Client Inspect**（`session/agent-busy: … owned by subagent routing`，已在页面 console 实测抓到） | 无法用 `Slots.listSubTree` / `Theme.listTokens` 出快照 | 本文改以随包源码确认 slot/token；建议主会话复验 |

## 附录 B：给实现阶段的 10 条结论（可直接执行）

1. 页面形态：**`main`（key=`token-manager`）+ `sidebar.panellist`（id 同名）**，不要抢 `conversation`/`plugins`/`settings.*` 等既有 key。
2. 注册一律走 `ctx.slots.inject(slotKey, () => ctx.slots.register(...))`，disposer 逆序清理；入口与整页同生共死，并保留「座位不可用 → 降级」分支（照抄 mnemon 的 `seat` 模式）。
3. 组件 props：`t`（声明 `locale`）、`inject()` 返回值、`useSessions`/`useWorkspaces`、`useStore`/`actions`、`renderSlot`；不要 import React 之外的官方包。
4. 样式：手插 `<style data-dsh-owner="dsh-token-manager">`，在 `ctx.effect` 的 disposer 里移除；只写 `var(--dsw-*)`/`var(--dsh-*)`，深色默认。
5. 顶部留白：`padding-top: var(--dsh-frame-top-clearance, 48px)`。
6. 文案：`locale/zh.json` + `locale/en.json`，`ctx.locale.register(ns,{zh,en})`，slot 注册带 `locale: ns`。
7. 数据：Host `ctx.webServer.register({kind:'prefix', path:'/token-manager/api'})`；**每请求先 `ctx.connection.requestRejection(req)`**；POST JSON 做服务端分页；CSV 走 GET + `Content-Disposition` 流式，BOM + 公式转义。
8. 聚合/原始数据留 Host；前端只拿当前页；不加「前端隐藏按钮」式权限。
9. 构建：esbuild `--format=cjs` + `banner/footer` 包成 `window.__ModuleLoader__.load({id, factory})`；`react`/`react-dom`/`react/jsx-runtime` 走 external；产物 `node --check` 自检。
10. 验收：真实浏览器 1600/897/390 三档 + 刷新 + 切语言 + 切主题 + 断网/空数据/超大结果 + 未授权直连 API 必须 403。
