# 社区视频脚本 · DSH Token Manager（45–60 秒）

> 目标平台：B 站 / 抖音 / 视频号 / YouTube Shorts
> 核心信息：**大型项目/长会话省 30%–50%，小项目省 5%–15%；压缩只对"反复携带的大工具输出"有效。**
> 数据标注：A/B 为真实模型调用实测；多项目百分比为真实历史会话的离线估算（已标注）。

## 1. 钩子（0–5 秒，必须放最前）

**大字幕：**
> 同一个项目，工具输出直接砍掉 **67%**；
> 一个长会话，Token 账单能省 **30%–50%**。

**口播：**
> 你每天让 AI 跑命令、看日志、修大项目，Token 有一大半浪费在"把同样的几万字日志反复发给模型"。这个插件把它压到 1/3，而且不用改模型、不改代码。

**画面：** `annotated-05-ab.png`（44,067 → 30,068，−31.8%）快速推近，数字跳动。

## 5. 不同项目能省多少（42–52 秒）

**口播：**
> 说人话：小项目总共就花几块钱，省也就省几毛，看不出来；
> 中型项目省 10%–25%；
> 真正值钱的是大型项目、长会话、反复修复——省 30%–50%，一个会话几块到几十块。

**画面：** `annotated-06-projects.png`（真实历史项目占比图）

| 项目类型 | 典型节省 | 绝对值 |
|---|---|---|
| 小型（博客/单页） | 5%–15% | 几毛 |
| 中型（官网/工具） | 10%–25% | 几毛~几块 |
| **大型修复 / 长会话** | **30%–50%** | **几元~几十元/会话** |

**字幕备注（小字）：** 多项目占比为历史会话离线估算；费用按公开参考价，实际以账单为准。

## 8. 发布文案（简介区）

**标题（任选）：**

> DSH Token Manager 是 DeepSeek Harness 的 Token 监控 + 压缩插件：逐调用四桶台账、11 类浪费检测、可逆工具输出压缩、任务/项目成本报告。实测长会话省 30%–50%，小项目省 5%–15%。默认只监控，压缩可随时关；错误行/代码读取不压缩，历史不改写。GitHub：zhirai-tech/dsh-token-manager
